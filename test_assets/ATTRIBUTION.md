## Generated Sound Effects

The following files were generated using ffmpeg for testing purposes:

- `beep_220hz.wav` - 220Hz sine wave, 1 second duration
- `beep_440hz.wav` - 440Hz sine wave (A4 note), 0.5 second duration
- `beep_880hz.wav` - 880Hz sine wave (A5 note), 0.3 second duration

These generated files are in the public domain (CC0).
